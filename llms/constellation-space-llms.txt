# Constellation Space (ConstellationOS)

> ConstellationOS is the ML-native operations platform for satellite fleets (Y Combinator, Seattle). Operators connect ground telemetry through one API and schema, run ML link forecasts on live fleet context (SNR and link fade, traffic, weather, jamming, conjunction), and act under operator policy with automated routing, stream isolation, and failover. The HTTP API is authenticated with scoped bearer tokens (cos_live_ / cos_dev_).

## API
- [ConstellationOS API base](https://api.constellation.space): production API host (staging: api-staging, dev: api-dev)
- [GET /api/v1/topology/](https://docs.constellation.space/api/topology): read fleet topology (scope topology:read)
- [POST /api/v1/telemetry/ingest](https://docs.constellation.space/api/telemetry): ingest telemetry (scope telemetry:write)
- [POST /api/v1/predictions/](https://docs.constellation.space/api/predictions): run ML predictions (scope predictions:run)
